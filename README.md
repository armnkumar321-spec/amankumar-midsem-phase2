## About
A React app that lists companies in a campus placement drive. It checks my eligibility (branch and CGPA) for each company, marks Dream Companies (10 LPA or more), and lets me apply to or withdraw from eligible companies.

## Pages
- `/` – Home: my profile and summary counts
- `/companies` – All companies with an Eligible / Not Eligible filter
- `/companies/:id` – Full details of one company
- `/applications` – Companies I have applied to

## Tech used
React, Vite, React Router, CSS

npm install
npm run dev
